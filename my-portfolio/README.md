# Flavio Fernandez Suarez — Portfolio

Personal portfolio built with React, Tailwind CSS and [Vite](https://vite.dev).

## Scripts

Run these in the `my-portfolio` folder:

- `npm run dev` (or `npm start`): starts the dev server at [http://localhost:3000](http://localhost:3000)
- `npm run build`: builds the site for production into the `build` folder
- `npm run preview`: serves the production build locally to check it
- `npm test`: runs the tests with Vitest in watch mode (`npx vitest run` runs them once)
